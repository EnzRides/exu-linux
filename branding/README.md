# Exu Linux Branding Guidelines

## Brand Identity

**Official Name**: Exu Linux
**Tagline**: Simple. Fast. Beautiful.
**Color Palette**:
- Primary: `#6C5CE7` (Purple)
- Secondary: `#A29BFE` (Light Purple)
- Accent: `#00B894` (Green)
- Dark: `#2D3436` (Dark Gray)
- Light: `#F5F6FA` (Off-White)

## Logo Usage

- Use high-quality PNG or SVG formats
- Maintain aspect ratio (1:1 for icon, 2:1 for horizontal logo)
- Minimum size: 32x32px
- Do not stretch or distort the logo

## Color Codes

```
Primary Purple:   RGB(108, 92, 231)  | HEX #6C5CE7
Light Purple:     RGB(162, 155, 254) | HEX #A29BFE
Accent Green:     RGB(0, 184, 148)   | HEX #00B894
Dark Gray:        RGB(45, 52, 54)    | HEX #2D3436
Off-White:        RGB(245, 246, 250) | HEX #F5F6FA
```

## Typography

- **Font Family**: Noto Sans (system default)
- **Headings**: Bold, 18-24pt
- **Body Text**: Regular, 11-14pt

## Assets Included

- `logo/` - Logo files (SVG, PNG)
- `wallpapers/` - Official Exu Linux wallpapers
- `colors/` - Color scheme files
- `splash/` - Boot splash screens
- `icons/` - Custom icon sets
