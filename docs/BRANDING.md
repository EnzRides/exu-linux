## Typography

- **Primary Font**: Noto Sans
- **Monospace Font**: Noto Mono
- **Headings**: Bold, 18-24pt
- **Body**: Regular, 11-14pt
- **Code**: Monospace, 10-12pt

## Logo Usage

### Guidelines
- Minimum size: 32x32 pixels
- Maintain 1:1 aspect ratio for icon
- Maintain 2:1 aspect ratio for horizontal logo
- Never distort or rotate the logo
- Always use full color on light backgrounds
- Use white version on dark backgrounds

### File Formats
- **SVG** - Scalable, preferred for web/design
- **PNG** - Raster, for applications
- **ICO** - For favicon/system icon

## Branding Elements

### Boot Screen
- Use purple as primary color
- Display "Exu Linux" prominently
- Include version number
- Use light gray for background

### Desktop Environment
- KDE Plasma as standard DE
- Apply color scheme globally
- Use official wallpapers
- Consistent widget styling

### Terminal
- Dark background (#2D3436)
- Light text (#F5F6FA)
- Purple highlights
- Konsole as default terminal

### Applications
- ExuFetch tool (system info)
- Branded help/about dialogs
- Consistent icon theme
- Exu color scheme for all apps

## Installer Branding
